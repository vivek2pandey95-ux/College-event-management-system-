# College Event Management System

A simple web application for managing college events and student registrations.

## Features
- Create college events
- View upcoming events
- Student event registration
- Registration/participant list
- SQLite database
- Responsive interface

## Technology
- Python
- Flask
- SQLite
- HTML/CSS

## Run locally
1. Install Python 3.
2. Open terminal in this folder.
3. Run `pip install -r requirements.txt`
4. Run `python app.py`
5. Open `http://127.0.0.1:5000/`
yt
## Project Objective
To simplify college event management by providing a centralized platform for event creation, student registration, participant management, scheduling, and communication.
